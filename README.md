# Work Tracker — плагин для Logseq

Личный трекер рабочих задач. Сделан на TypeScript + React + Vite с использованием `@logseq/libs`, по архитектуре близкой к примеру [logseq-plugin-git](https://github.com/haydenull/logseq-plugin-git).

## Возможности

- создание, редактирование и удаление задач;
- статусы: «К выполнению», «В работе», «Готово»;
- приоритеты: низкий, средний, высокий;
- срок выполнения, проект и заметки;
- быстрые счётчики-фильтры и поиск;
- отметка выполнения одним нажатием;
- хранение данных в текущем графе Logseq на странице `Work Tasks`;
- открытие трекера через иконку на панели и Command Palette.

## Сборка

Требуется Node.js 20+.

```bash
npm install
npm run build
```

Готовый плагин находится в `dist/`.

## Установка в Logseq

1. Выполните `npm run build`.
2. В Logseq включите Developer mode в настройках.
3. Откройте Plugins → Load unpacked plugin.
4. Выберите каталог проекта (или каталог `dist`, если ваша версия Logseq ожидает собранную папку).
5. Включите Work Tracker. Откройте его кнопкой ✓ на панели или через Command Palette → `Work Tracker: открыть трекер задач`.

## Хранение

Плагин создаёт страницу `Work Tasks` в текущем графе и сохраняет сериализованный список задач в служебном блоке `work-tracker-data::`. Не удаляйте этот блок вручную, если хотите сохранить задачи.

## Примечания

- Это первая рабочая версия без синхронизации с внешними сервисами.
- Структура хранения намеренно изолирована на одной странице, чтобы не засорять ежедневные журналы.
- Перед публикацией в Marketplace рекомендуется проверить сборку на используемой версии Logseq Desktop и при необходимости обновить `@logseq/libs`.
